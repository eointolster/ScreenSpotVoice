Allow your microphone

Chrome needs this permission on a full extension tab before ScreenSpot Voice can use the microphone from its side panel.

This setup check stops its temporary microphone track immediately. Audio is sent to Gemini only after you return to the webpage and start a session.

Checking microphone permission…

If Chrome has blocked permission, open chrome://extensions → ScreenSpot Voice → Details → Site settings, allow Microphone, then return here and try again.
